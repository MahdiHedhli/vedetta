# Vedetta v0.1.0-beta.1 — First Public Beta 🔭

**A self-hosted network watchtower for everyone.** Vedetta is an open-source
(AGPLv3), LAN-first SIEM and threat-intelligence platform for home networks and
small businesses. Know every device, detect threats, and own your data — no
cloud dependency, no subscriptions.

This is Vedetta's **first public beta**. Local detection works entirely on your
own hardware; the optional community threat network makes every instance smarter.

---

## What you get today

- **Device discovery** across ARP, DHCP, mDNS, and SSDP/UPnP, with L2
  fingerprinting from native sensors.
- **Passive DNS monitoring** via libpcap, with local threat scoring, enrichment,
  and detectors for DGA-like domains, beaconing, DNS tunneling, and rebinding.
- **EOL router & camera risk detection** for the models called out in the
  FBI IC3 FLASH 2026-03-12 advisory, with risk scoring on suspicious behavior.
- **UniFi log ingestion** (CEF/syslog → firewall events; syslog path implemented)
  and **optional Pi-hole / AdGuard Home** pollers.
- **Core + Sensor architecture:** a Docker-based Core (API, dashboard, local
  SQLite) plus lightweight native sensors for macOS and Linux.
- **Community threat network (opt-out):** contribute privacy-reduced,
  **pseudonymous** telemetry to a shared advisory feed. For beta, only
  Core-confirmed **known-bad block-list indicators** and aggregate counts are
  shared — never device identities or raw query names.

## Security & privacy posture

This beta shipped after an independent, multi-round security review. Highlights:

- **Scoped bearer tokens** (admin / read / ingest / sensor) with strict-admin
  enforcement on management routes.
- **Admin-gated sensor enrollment:** single-use setup code at bootstrap; new
  sensors require an admin bearer or a single-use enrollment code; sensor
  identities cannot be silently hijacked or re-enrolled after revocation.
- **Loopback-first transport:** Core and the dashboard bind to `127.0.0.1` by
  default. Remote sensors go through a documented TLS reverse proxy — insecure
  LAN exposure is never the silent default.
- **Telemetry is on by default and opt-out** — disable it with
  `VEDETTA_TELEMETRY_OPTIN=false` or the dashboard toggle. Source IPs, MACs, and
  hostnames are stripped at the source and never transmitted. Sharing is
  **pseudonymous, not anonymous** — see [PRIVACY.md](../../PRIVACY.md).

## Install

```bash
git clone https://github.com/MahdiHedhli/vedetta.git
cd vedetta
./scripts/gen-env.sh        # generates .env credentials + first-admin setup code
docker compose up -d
```

Open the dashboard at `http://localhost:3107`, run the onboarding wizard with the
setup code, then mint an enrollment code and install a sensor. Full steps —
including the same-host vs. remote (`--core`) transport guidance — are in the
[README Quick Start](../../README.md#quick-start).

## What "beta" means

- Local detection works with **zero cloud dependency**; the community feed is
  advisory-only and never a runtime dependency.
- The **native sensor install** still assumes some networking comfort and
  elevated privileges for the strongest local visibility.
- **Windows:** Core runs on Windows via Docker; the native sensor that provides LAN visibility is macOS/Linux today, with Windows on the roadmap.
- The community feed grows more useful as the reporter base grows — early
  contributions help build consensus.
