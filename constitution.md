# Vedetta Constitution

The canonical project constitution lives at
[`.specify/memory/constitution.md`](.specify/memory/constitution.md)
(GitHub Spec Kit convention).

It governs every spec, plan, and implementation in this repository, including the
non-negotiable **Environment Data Handling** rules originally authored in this file:
live-environment data is local-only, tracked files use RFC 5737 / synthetic values
only, and environment-specific identifiers are a release blocker before any public
commit.
